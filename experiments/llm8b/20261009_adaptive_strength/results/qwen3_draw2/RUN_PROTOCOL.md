# First-stage falsification protocol — frozen before outcomes, 2026-10-09

Scope: only actual re-rounded linear-group residual, search cost and independent-window residual generalization. No commutator, block/full-suffix NLL, whole-policy construction, rescue claim or 4-bit extension unless this first stage passes. Preserve all earlier evidence.

Four conditions: Qwen3-8B / Meta-Llama-3-8B × existing calibration draws 1/2. Bits=2, asymmetric group128 quantizer with scales/zero-points re-estimated for each candidate. Teacher BF16 original; student entire RTN prefix/native blocks. Intervene on blocks 1, floor(L/2), L-2 (zero-based), all four map groups (qkv, o, gate/up, down). The three early/middle/late blocks and all groups give 12 states per condition, 48 total. Each intervention starts from exactly the same untouched RTN current block and prior prefix, and is discarded after scoring. Do not propagate trial corrections. This is not GPTQ/WaterSIC reproduction.

Use parent selection_controls 4K runs' exact token arrays: fit2048, select4096, diagnostic8192, length512. All states follow own teacher/RTN trajectories. No new token choices. These independent-role windows have already been inspected in earlier campaigns, so this is exploratory holdout evidence. Original calibration and all data hashes are retained.

Ridge fitting exactly reuses previous damping1 helper. For each map, construct its calibration-fitted weight correction. On SELECTION tokens form teacher target, baseline quantized output and actual correction output. Analytic center is the clipped inner-product ratio for the frozen-baseline-rounding-error quadratic along this actual ridge direction; use group sum of per-map mean squared errors consistently. No orthogonal-projection substitution. Degenerate direction: choose zero and flag; relative denominator tolerance1e-12 compared to group target energy (absolute floor1e-30). This is a proposal, not a real-codebook optimum. Coefficients are determined from selection statistics, and can themselves overfit.

Fixed controls: individual zero, half, full. Dense reference: ten nonzero points 0.1,...,1.0 plus the common cached zero fallback. Theory: center, then center+0.1 if center<=0.5 else center-0.1, clipped; choose smallest selection residual among these and cached zero. Random controls: one uniform coefficient for comparison to the center; two uniform candidates plus cached zero as same-count search control. RNG seed parent_seed+100000*bits+100*layer+group, unrelated to outcomes. Fixed two-point search {0.5,1} plus zero is an additional equal-count control. All adaptive choices use selection residual ONLY, ties choose smaller coefficient. Cached zero and any duplicate candidates are recorded; no fictitious evaluation cost for duplicate zero.

Point 1: report standalone analytic-center paired residual differences vs half and one random coefficient on select and diagnostic data, plus candidate-curve rank correlation of frozen-error prediction with actual re-quantized MSE on the fixed 11-point curve, and relative regret vs best grid. Report direction degeneracy and center concentration at endpoints. The primary continuous-prior gate requires the center to have lower mean target-normalized residual than BOTH half and random1 on BOTH selection and diagnostic data, separately in each of four model/draw conditions. If it fails, withdraw the stand-alone continuous-prior candidate for this setting; do not rename or add features. This is a conservative operational screen, not a significance test or proof of general impossibility.

Point 2: common reference gain is the zero residual minus chosen residual on the SAME dataset/state. Report full curves and all three fixed settings. Retained gain uses summed target-normalized improvements over all 12 states in a condition divided by corresponding dense-grid improvement; undefined if denominator<=1e-12, not an automatic pass. Require theory2 at least90% dense gain on both select and diagnostic and measured total selection-stage time <=20% grid time in each condition for the proposed frontier claim. Also compare fixed2/random2; no novelty credit for wins they also achieve at lower cost. A count of2 vs10 is never by itself a20% runtime result.

Timing: synchronize GPU, separate common preparation (capturing fit/select states, teacher targets, baseline quantization/score, ridge and direction), theory moment estimation, candidate quantize+selection-score and heldout audit. Run three warm-cache timing repeats with rotated strategy order; report median. Theory timing recomputes its moments and candidates each repeat; grid/fixed2/random2 repeat their candidates. Both common-inclusive ratio and incremental ratio are reported. Model load and the shared prefix/teacher pass are excluded from the per-state decision timings, explicitly; timing is not end-to-end quantization deployment. Individual fixed strengths need no coefficient-selection pass; their validation scoring is audit work, not claimed decision cost. No diagnostic score/metadata work belongs to selection time.

Point 3: measure heldout regret, mean target-normalized residual, harm vs zero/half and diagnostic-minus-selection gain gap for each policy. 'More stable than grid' requires theory2 lower mean diagnostic normalized residual and no larger diagnostic harm count vs zero in every model/draw condition; report all contrary cases. Do not equate a selection/diagnostic gap with causally established overfitting; text composition and fixed2K fitting may matter.

Validation before/along running: source/token hashes; zero correction reproduces native RTN weights; repeated probes leave all RTN current-block weights unchanged; native whole-model teacher/RTN prefix decomposition parity on one short sequence; zero/degenerate analytic directions; known quadratic minima; bounded 2-bit codes; alpha0 actual residual equals frozen model; test tie/near-tie and adaptive argmin; all states finite. Never drop severe 2-bit states after inspecting them.

Stop: complete the four predeclared slices and their validity checks, then apply all gates without adding runs or changing thresholds. No whole-model extension if the first continuous-prior gate fails. A valid negative result is the planned outcome, not a reason to retune.
